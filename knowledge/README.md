# Ubicación de documentos del asistente

Esta carpeta no se indexa. Agrega los documentos aprobados en `knowledge_base/`, que es la ubicación que lee `npm run knowledge:update`.

El asistente también consulta los productos publicados en `assets/products.js`. El índice se genera en `knowledge_base/index.json` y se publica junto con los documentos.

No pongas aquí información privada ni datos de precio o existencia que no estén aprobados para clientes.
